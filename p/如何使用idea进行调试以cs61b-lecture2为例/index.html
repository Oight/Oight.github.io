// DogProblemBeautifulSolution.java
package lecture2;

public class DogProblemBeautifulSolution{
    public static Dog[] largerFourNeighbors(Dog[] dogs) {
        Dog[] returnDogs = new Dog[dogs.length];
        int cnt = 0;

        for(int i = 0; i < dogs.length; i++) {
            if (isBiggestOfFour(dogs, i)) {
                returnDogs[cnt] = dogs[i];
                cnt += 1;
            }
        }

        returnDogs = arrayWithNoNulls(returnDogs, cnt);
        return returnDogs;
    }

    public static Dog[] arrayWithNoNulls(Dog[] dogs, int cnt) {
        Dog[] noNullDogs = new Dog[cnt];
        for (int i = 0; i < cnt; i++) {
            noNullDogs[i] = dogs[i];
        }
        return noNullDogs;
    }

    public static boolean validIndex(Dog[] dogs, int index) {
        return index >= 0 && index < dogs.length;
    }

    public static boolean isBiggestOfFour(Dog[] dogs, int i) {
        boolean isBiggest = true;
        for (int j = -2; j <= 2; j += 1) {
            int compareIndex = j + i;

            if (validIndex(dogs, compareIndex)) {
                if (dogs[compareIndex].weightInPounds >= dogs[i].weightInPounds) {
                    isBiggest = false;
                }
            }
        }
        return isBiggest;
    }


    public static void main(String[] args) {
        Dog[] dogs = new Dog[] {
            new Dog(10),
            new Dog(15),
            new Dog(20),
            new Dog(15),
            new Dog(10),
            new Dog(5),
            new Dog(10),
            new Dog(15),
            new Dog(22),
            new Dog(20)
        };

    Dog[] bigDogs1 = largerFourNeighbors(dogs);

    for (int k = 0; k < bigDogs1.length; k++) {
        if (bigDogs1[k] != null) {
            System.out.println(bigDogs1[k].weightInPounds + " ");
        }
    }
    System.out.println();
    }
}

代码比较简单。功能就是给出一个数组，然后通过比较得到所有比它前两个数和它后两个数都大的数的数组，然后返回。

调试

对于[10, 15, 20, 15, 10, 5, 10, 15, 22, 20]这个数组，我们预期返回20和22这两个数，然后我们看看当前代码会返回什么：

可以看到返回空值，这显然不是我们想要的结果。

然后我们就可以开始调试，找出代码到底哪里出了问题。

我们首先在DogProblemBeautifulSolution.java的第47行处下断点（下断点的作用是让代码在我们指定的地方停下来方便我们观察）

然后我们点击调试按钮进行调试

可以看到，代码在第47行处停下，这里是没有执行第47行代码的

然后我们需要一步步执行代码，来观察代码在运行过程中发生了什么，这里我们需要了解步进（Step Into）和 步过（Step Over）这两个概念。

步过是指运行至这个函数结束处（如果所在行为函数），也就是一行行运行代码

步入是指进入函数内部观察程序行为（如果所在行为函数）。

其快捷键分别为F8和F7。

我们点一下F8

可以看到函数执行后产生了我们预设的数组[10, 15, 20, 15, 10, 5, 10, 15, 22, 20]

由于代码的核心逻辑都在largerFourNeighbors函数中，所以我们F7步入看看

可以看到这里跳到了largerFourNeighbors里面，和按F8产生了不同的效果，如果感兴趣可以停掉调试重新再largerFourNeighbors函数处按F8看看会有什么不同。

bad news

这里将isBiggest设为了false。这就与我们预期的结果不符了。

我们现在找到了问题出在哪，由于调试器只能向前走不能向后走，我们第一次观察到异常行为之后有问题的代码已经被执行完了，如果我们想再仔细看看代码到底出了什么问题，就需要重新调试了。

但这次我们就不需要再将断点下那么远了。我们知道了问题具体出在哪，就不用再关心前面没有出问题的逻辑了。

我们把调试停掉，然后取消掉原来在第47行设置的断点，把断点设置在第32行（在CS61B中将断点设在了第9行，但我觉得这个没什么很大的关系，看个人习惯）
